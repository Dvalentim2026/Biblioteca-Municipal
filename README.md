# Biblioteca-Municipal
Trabalho de campo - Introdução a Algoritmo e programação
Sistema de Gestão de Biblioteca Municipal

## 1. Descrição
Sistema desenvolvido em Java para a disciplina de Introdução a Algoritmos e Programação - UniSCED.
O sistema permite o registo de livros e usuários, controle de empréstimos e devoluções, e geração de estatísticas básicas.
Os dados são armazenados em vetores durante a execução.

## 2. Funcionalidades
- Registar Livro
- Consultar Catálogo por título ou autor
- Registar Usuário
- Emprestar Livro
- Devolver Livro
- Estatísticas: Livro mais emprestado e total do acervo

## 3. Tecnologias Utilizadas
- Linguagem: Java JDK 17
- Paradigma: Programação Orientada a Objetos
- Estrutura de Dados: Vetores/Arrays

## 4. Como Configurar e Executar
Pré-requisito: Ter o JDK 17 instalado.

1. Clone o repositório:
   git clone
2. Entre na pasta:
   Javac BibliotecaMunicipal. 
3. Compile:
   javac TrabalhoDeCampo.java
4. Execute:
   java TrabalhoDeCampo
